- 🎯 **Цветовая кодировка** — протоколы выделены разными цветами

## 🚀 Установка

```bash
# Клонировать репозиторий
git clone https://github.com/ginolrewadsb11/studious-umbrella.git
cd studious-umbrella/web

# Установить зависимости
npm install

# Запустить dev сервер
npm run dev

# Собрать для продакшена
npm run build
```
